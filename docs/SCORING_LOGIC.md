# 评分逻辑

规则引擎将各维度分数归一到 0-100，由 WeightManager 按市场状态加权融合。

- 价值：PE/PB 历史分位、ROE、营收增速、净利增速、股息率。财务来自 baostock 季度盈利/成长/偿债接口。
- 趋势：均线排列、MACD、RSI、布林带位置、成交量趋势、ATR。
- 资金面：优先用真实主力净流入/北向/融资/股东户数；**无真实资金数据时退化为量价代理**（量比、OBV 趋势、CMF 资金流向量、换手率趋势）。
- 行业：行业相对强弱、个股相对行业超额。行业强弱用**官方一级行业指数**(沪深300行业 000910-000919 + 中证全指补医药/金融,市值加权,baostock 可取),证监会行业→中证一级的映射见 `src/industry/sector_map.py`;`industry-scan` 的细分热门行业按成分股近一年涨幅**中位数**排名(对妖股稳健)。
- 事件：涨跌停信号、近 3 日异常波动。
- 消息面：近 30 日公告/新闻标题的利好利空倾向（规则词典）；更深的语义研判由 DeepSeek 在 analyze 阶段完成。

金融业(银行/保险/证券)天然高杠杆，豁免一般资产负债率上限过滤。

冲突处理：引擎分歧超过隔离阈值(60)时整只隔离；分歧在 40-60 之间时，**保守状态下下调分歧引擎的置信度(降权)而非取最小值**，避免把深度低估等真实信号直接抹平;特定状态(牛市偏趋势、熊市偏价值等)向优先引擎靠拢。

缺失数据不按 50 分填充，缺失子项不参与该引擎评分，并降低该引擎置信度。置信度低于 0.3 的引擎标记为不可用，不参与综合评分。北向资金单股数据不可得时记为中性描述，并从置信度分母中移除。

行业相对强弱基于本地 `industry_index` 表计算近 20 日行业收益排名；行业资金在阶段一用行业指数成交量变化作为可解释代理指标。全市场扫描阶段不逐只访问 AKShare，评分输入来自本地数据库。

阶段二/三扩展模块保持同一评分结果格式：调度器负责定时触发更新和扫描，通知服务发送扫描摘要，模拟盘只消费本地候选池和价格字段，不改变评分本身。

## AI 分析层（DeepSeek）

规则引擎负责可解释的硬指标打分，大模型负责在这些分数与信号之上做综合研判。
`src/llm/` 把单只股票的评分报告（各引擎分数、置信度、信号、估值分位、市场状态、过滤/冲突结论）
压缩成上下文交给 DeepSeek，要求其严格返回 JSON：评级、置信度、看多/看空逻辑、风险与操作建议。
大模型只依据给定的量化结果做研判，不引入未提供的信息；未配置 Key 或调用失败时返回降级结果，
不影响规则评分链路。结论仅供研究参考，不构成投资建议。

## 回测选股口径

回测支持两种选股口径：`score`（默认）在每个调仓日用同一套规则引擎对每只股票做时间点评分并取 Top N，
与系统对外推荐逻辑一致，能真正检验"推荐什么就回测什么"；`momentum` 用 60 日动量作为基准对照。
